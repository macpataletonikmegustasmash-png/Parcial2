Proyecto personajes de videojuegos

Este proyecto presenta una lista de jugadores de Smash Ultimate en Puebla y los personajes que usan
También se pueden agregar datos manualmente.

¿Por qué existe esto? ¿Para qué sirve?
Sirve para llevar un registro de los jugadores que se inscribieron a un torneo.

Tecnologías utilizadas:
- IntelliJ
- Java Class

Requisitos Previos:

- Editor de código: IntelliJ

Instalación:

Simplemente abre el archivo con el editor de código


Uso:

Creo que es lo suficientemente intuitivo; está hecho para que cualquiera lo use sin perderse

Características:
- Ingresa, elimina y observa los jugadores en la lista
- Crea nuevos patrones
- Elimina patrones
- Visualiza todo el array
